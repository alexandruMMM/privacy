Politica de Confidențialitate — Analize Medicale

Data intrării în vigoare: 1 septembrie 2026

Această Politică de Confidențialitate descrie modul în care aplicația Analize Medicale („aplicația") gestionează datele atunci când o folosești.

1. Rezumat

  • Aplicația este destinată monitorizării personale a rezultatelor de analize medicale, cu stocarea datelor local, pe dispozitiv.
  • Aplicația nu necesită cont și nu încarcă datele tale pe niciun server propriu.
  • Pentru citirea automată a valorilor dintr-un document scanat, conținutul acestuia este trimis către Claude API (Anthropic PBC), strict în acest scop — vezi secțiunea 5.

2. Date pe care le procesăm

Aplicația procesează următoarele date, doar pentru a oferi funcționalitatea:

  • Documente medicale: fotografii sau fișiere PDF ale buletinelor de analize, scanate sau importate de tine.
  • Date de sănătate extrase din documente: nume analiză, valoare, unitate de măsură, interval de referință, dată, cabinet/laborator emitent.
  • Preferințe locale: setări ale aplicației și cabinete medicale uniformizate.

Nu colectăm intenționat:

  • nume, e-mail, CNP sau alte date de identitate;
  • identificatori de publicitate;
  • date de localizare.

3. Permisiuni folosite pe dispozitiv

  • Cameră — pentru scanarea documentelor (dacă alegi această opțiune).
  • Stocare/fișiere — pentru importul de imagini sau PDF-uri existente pe dispozitiv.

4. Distribuire și transferuri

  • Aplicația îți permite să exporți un backup criptat, protejat cu o parolă stabilită de tine; fișierul este creat local și trimis doar prin canalul ales de tine (ex. e-mail, stocare cloud personală).
  • Aplicația îți permite să exporți rapoarte PDF cu rezultatele analizelor, la cererea ta.
  • Nu vindem și nu închiriem datele tale către terți.

5. Servicii terțe — Claude API (Anthropic)

Pentru a extrage automat valorile dintr-un buletin de analize scanat, imaginea sau PDF-ul documentului este trimisă printr-o conexiune criptată către API-ul Claude, operat de Anthropic PBC, exclusiv pentru a citi și structura textul analizelor medicale conținute în document.

Conform politicilor comerciale de API ale Anthropic, datele transmise prin API nu sunt folosite pentru antrenarea modelelor. Poți consulta politica de confidențialitate a Anthropic la anthropic.com/legal/privacy.

Aplicația nu integrează alte servicii de analiză, publicitate sau urmărire a utilizatorilor.

6. Securitatea datelor

  • Toate datele analizelor și documentele originale sunt stocate local, pe dispozitivul tău.
  • Poți șterge definitiv toate datele din aplicație oricând, din Setări → Zonă periculoasă.
  • Recomandăm folosirea unui cod de blocare pe dispozitiv și păstrarea sistemului de operare actualizat.

7. Drepturile tale

Deoarece toate datele sunt stocate local, ai control direct asupra lor: le poți vizualiza, edita sau șterge oricând din interfața aplicației. Pentru întrebări legate de procesarea documentelor prin Claude API, ne poți contacta la adresa de mai jos.

8. Confidențialitatea copiilor

Aplicația nu colectează intenționat date cu caracter personal de la persoane sub 16 ani.

9. Modificări ale politicii

Putem actualiza această politică periodic. Modificările vor fi reflectate prin actualizarea datei de intrare în vigoare de mai sus.
